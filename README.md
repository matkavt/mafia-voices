# mafia-voices

Voice models used by the party game «Mafia & Werewolf: Narrator» (matkavt), mirrored here so that downloads stay reliable.

## supertonic-3-int8-2026-05-11

Supertonic 3 text-to-speech by **Supertone Inc.** — https://huggingface.co/Supertone/supertonic-3
int8 ONNX build as packaged by sherpa-onnx (k2-fsa): `sherpa-onnx-supertonic-3-tts-int8-2026-05-11` from https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models

The files in the release are **unmodified** copies of that package.
